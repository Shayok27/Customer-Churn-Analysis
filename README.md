# Customer Churn Analysis

## Project Overview

This project analyzes customer churn and banking behavior using Excel, SQL, Power BI, and DAX.

The goal of this project is to understand customer characteristics, account balances, transaction behavior, and patterns related to customer churn.

## Tools Used

- Microsoft Excel
- SQL
- Power BI
- DAX

## Dataset

The dataset contains customer information, demographics, account balances, transaction activity, branch information, and churn status.

## Key Findings

- The dataset contains 28,382 customers.
- Approximately 18.53% of customers are classified as churned.
- Customer balances vary across occupations, cities, branches, and age groups.
- Churn patterns differ across customer demographics and network categories.
- Some cities and branches show noticeably different customer churn levels.
